# 项目知识（PageAgent 全局速览）

## 系统定位

这是一个通用后台管理模板（Art Design Pro），内置系统管理能力：认证登录、用户/角色/菜单/字典、操作日志、登录日志、文件上传。业务功能集中在「系统管理」菜单下。

## 模块地图

- 工作台：`#/dashboard/console`（仪表盘统计页）
- 系统管理 `#/system`：
  - 用户管理 `#/system/user`
  - 角色管理 `#/system/role`
  - 菜单管理 `#/system/menu`
  - 字典管理 `#/system/dict`
  - 操作日志 `#/system/oper-log`
  - 登入日志 `#/system/login-log`
- 个人中心 `#/system/user-center`（隐藏页面，不在菜单中）

## 术语表

- 角色码：`R_SUPER` 超级管理员（全部功能）；`R_ADMIN` 普通管理员（功能受限）
- 权限码：`add`（新增）、`edit`（编辑）、`delete`（删除），控制按钮显隐
- 状态值：`0` 禁用、`1` 启用
- 字典两层结构：「字典类型」是分类（如"性别"），「字典数据」是类型下的条目（如"男/女"）

## 通用操作约定

- 表格操作列是图标按钮，按 aria-label 或 title 识别（查看、编辑、删除、更多）
- 新增/编辑通过弹窗完成；删除操作有二次确认弹窗
- 次要操作（如「分配权限」「重置密码」）收纳在操作列的「更多」下拉菜单中，先点「更多」再选菜单项
- 完成后用中文简短回复结果

## 注意事项（坑）

- `R_ADMIN` 账号看不到「角色管理」「菜单管理」——页面或菜单缺失可能是权限所致，不是故障，不要反复寻找
- 「个人中心」不在菜单里，通过右上角头像进入
- 页面以多标签形式打开，完成任务后不要关闭无关标签
